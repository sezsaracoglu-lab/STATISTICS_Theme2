🎯 Accuracy · Reliability · Validity — The Triangle

Accuracy (Systematic Error / BIAS)

Refers to how close a measurement is to the true value. Affected by systematic error (bias). Error is consistent and predictable.

Example: A scale that always shows +2 kg too much. ✓ Accurate ≠ Reliable; ✓ You can be consistent but wrong.

Reliability (CONSISTENCY)

Refers to the consistency or repeatability of a measurement. A measurement is reliable if it produces similar results under consistent conditions, indicating low random measurement error.

⚠️ Reliability concerns consistency, NOT accuracy or validity.

Validity (MEASURING WHAT YOU THINK)

Whether the instrument actually measures the intended construct. Accuracy measures the construct it is intended to measure. Validity concerns the meaning and interpretation of test scores, not merely their consistency.

⚠️ A test can be reliable but not valid!

📐 Five-Number Summary & IQR — Step-by-Step

Five Components

  • 1. Minimum — smallest value
  • 2. Q1 — 25th percentile (First Quartile)
  • 3. Median (Q2) — 50th percentile
  • 4. Q3 — 75th percentile (Third Quartile)
  • 5. Maximum — largest value

Worked Example

Dataset: 4, 7, 10, 12, 15, 18, 21, 25, 30 (already sorted, n=9)

  • Step 1: Sort smallest→largest ✓
  • Step 2: Median (Q2) = middle value = 15
  • Step 3: Lower half = 4, 7, 10, 12 → Q1 = (7+10)/2 = 8.5
  • Step 4: Upper half = 18, 21, 25, 30 → Q3 = (21+25)/2 = 23
  • Step 5: Min = 4, Max = 30
  • IQR = Q3 − Q1 = 23 − 8.5 = 14.5

Identifying Outliers — 1.5 × IQR Rule
Lower fence = Q1 − 1.5(IQR)   |   Upper fence = Q3 + 1.5(IQR)
Example: Q1=8.5, Q3=23, IQR=14.5 → Lower fence = 8.5 − 1.5(14.5) = −13.25; Upper fence = 23 + 1.5(14.5) = 44.75. All values between −13.25 and 44.75 → no outliers. Use phrase "suspected outliers" in exams.
📐 Variance & Standard Deviation — Formulas & Steps

Population Variance (σ²)

σ² = Σ(x − μ)² / N

Use when data include entire population

Sample Variance (s²)

s² = Σ(x − x̄)² / (n − 1)

Use when data are a sample from a larger population (most exams). Divide by n−1 (Bessel's Correction) to correct bias in estimating population variance.

Standard Deviation

σ = √σ²  (population)
s = √s²  (sample)

SD = square root of variance. Returns to original units. "Typical distance from the mean."

Step-by-step (data: 2, 4, 6, 8, 10):
Step 1: x̄ = (2+4+6+8+10)/5 = 6
Step 2: Deviations: −4, −2, 0, +2, +4
Step 3: Square deviations: 16, 4, 0, 4, 16
Step 4: Sum = 40
Step 5: s² = 40/(5−1) = 10 (sample variance)
Step 6: s = √10 ≈ 3.16 (sample standard deviation)

⚡ Linear Transformation — x_new = a + bx

Part 1: a — shifting the zero point

The constant a SHIFTS the origin (where zero is). Changes where zero starts. Example: Celsius → Fahrenheit needs a because 0°C ≠ 0°F (0°F = −17.8°C). Without a, the conversion would be wrong.

Part 2: b — changing the unit size

The constant b rescales the variable (changes size of one unit). Zero speed is the same in both systems (m/s and km/h) → no shift needed (a = 0). But unit size changes: 1 m/s = 3.6 km/h, so b = 3.6.

Q-Q Plot (Normal Quantile Plot)

Used to assess whether data come from a normal distribution. A normal quantile plot compares:
• The observed data values with
• The expected values from a normal distribution

Each point represents one observation.

⚠️ When a stemplot or histogram appears roughly symmetric and unimodal, visual inspection alone is NOT precise enough.

How to Read a Q-Q Plot

  • Points close to a straight line → data approximately normally distributed ✓
  • Systematic deviations from straight line → data are NOT normally distributed ✗
  • Curved shape → skewed data
  • S-shape → tails too heavy or too light
  • Random small noise is fine
  • Patterned deviation is not fine
  • Memory hook: "Outliers refuse to stand in line"
The optional reference line on a Q-Q plot: A reference line may be drawn where mean = sample mean and standard deviation = sample standard deviation. This line serves as a benchmark — "this is where normal data should be." Do the points follow it, or do they drift away?
📏 Conceptual vs Operational Definitions
TypeWhat it answersPropertiesExamples
Conceptual Definition (THE IDEA)"What do we mean by this concept?"Abstract; shared meaningStress = a psychological state of perceived pressure; Intelligence = ability to reason, solve problems, learn; Distraction = reduced attentional focus on a primary task
Operational Definition (THE MEASUREMENT)"How exactly did we measure it?"Concrete; observable; replicableStress = score on a 10-item stress questionnaire; Intelligence = IQ test score; Distraction = reaction time delay while driving
A variable MUST have an operational definition to be used in research. Conceptual definitions ensure scientific clarity, not measurement.
📏 Rate vs Count — Why We Standardize Data

Count

Raw number of occurrences. Counts can be misleading when group sizes differ. Same count ≠ same success when sample sizes differ.

Rate

Compares an outcome relative to the number of cases. Rates allow fair comparison.
Example: University A: 100 passes/1000 → 10%; University B: 100 passes/400 → 25%. Same count ≠ same success!

Hypothetical Constructs

A variable that cannot be directly observed. Is inferred from behavior or responses. You never observe the construct itself — you observe indicators.
Examples: Hunger, Motivation, Attention, Intelligence, Anxiety
